# Billing

PineNexus is pay-as-you-go. There is no monthly subscription fee.

1. Sign in at the [dashboard](https://apinexusdev.com). Public self-serve registration is currently closed, so you need an existing account.
2. Add balance with Stripe.
3. Usage is deducted from that balance as you call models.

Per-model rates are published on the [model square](https://apinexusdev.com/pricing). This page does not copy unit prices; check that page for the current list.

After you have balance, create an API key in **Tokens** and send it as `Authorization: Bearer YOUR_API_KEY`. See the [quick start](/#quick-start) and [API examples](/api-examples) to make your first call.
