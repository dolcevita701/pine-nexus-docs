# Billing

PineNexus is pay-as-you-go. There is no monthly subscription fee.

1. Sign in at the [dashboard](https://apinexusdev.com) with Google or GitHub.
2. New accounts automatically receive $1 in trial credit.
3. Create an API key in **Tokens** and make a test call.
4. When you want more balance, add funds with Stripe. Usage is deducted from your balance as you call models.

Per-model rates are published on the [model square](https://apinexusdev.com/pricing). This page does not copy unit prices; check that page for the current list.

Send your API key as `Authorization: Bearer YOUR_API_KEY`. See the [quick start](/#quick-start) and [API examples](/api-examples.html) to make your first call.
